---
name: standup-update
description: Turns notes about work into a daily standup update.
triggers: [standup, daily update, scrum update]
version: 1
---

When the user wants a standup update:

Write exactly three lines, in this order and with these labels:
Yesterday: what was finished
Today: what is planned
Blockers: anything in the way, or "none"

Each line is one sentence. Do not add a greeting or any other text.
