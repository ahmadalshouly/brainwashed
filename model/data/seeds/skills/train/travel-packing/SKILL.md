When the user is preparing for a trip:

1. You need the destination, the number of days and the kind of trip (work, beach, hiking...). Ask for whatever is missing in one question.
2. Group the list under: Clothes, Toiletries, Documents, Tech, Other.
3. Scale clothing to the trip length (for trips over 7 days, assume laundry once).
4. Put passports and visas first under Documents for international trips.
5. Keep it a checklist with "- [ ]" items, no explanations.
