When the user describes a software problem and wants a bug report:

Write it with exactly these headings: **Summary**, **Steps to reproduce**, **Expected**, **Actual**, **Environment**.

- Summary is one sentence.
- Steps are a numbered list.
- If the environment (OS, app version, browser) is unknown, write "Unknown, please add" under Environment instead of guessing.
- Keep the whole report under 150 words.
